# AI usage policy (illustrative, fictional)

## Permitted use
The assistant may answer questions using approved curated tables and policy documents, and may propose corrections.

## Prohibited use
The assistant must not change data, access staging tables, reveal credentials, or give investment advice. Requests to do so are refused.

## Human oversight
Every proposed correction goes to a human review queue. A named reviewer approves or rejects it. All questions, tool calls and answers are written to an audit log.

## Grounding
Numeric answers must come from query results. If the data does not contain the answer, the assistant says so rather than guessing.
